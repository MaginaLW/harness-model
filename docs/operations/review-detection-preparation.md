# 契约检出研究的真实观察准备

本页把[已采用的起步范围](../superpowers/specs/review-detection-admission.md)转为后续自然工作的移交流程。当前交付仅为准备：本轮未登记或核定实际合格候选、真实机会或裁定记录，`T0/T1` 未设置，30 日窗口尚未启动。[离线数学工具](review-detection.md)只接受 synthetic 计数，不接收真实记录；准备完成不把它升级为真实评分接口。

## 准备候选与来源

等本仓自然发生仅含 `docs/**` 普通文档、且包含 `docs/superpowers/specs/**` 契约内容的工作，再核对其首次非作者专项审核。不得为凑样本创建任务、制造缺陷、追加审核或追溯纳入已有报告。直接矛盾类的可检验要求、先前适用契约及版本，以[协议](../superpowers/specs/review-detection-protocol.md#2-机会裁定审核与匹配的顺序)为准。

协调者复用该工作的既有公开 Git／PR 原件。正式 task 仍按原 CLI、context 和 strict Schema 使用；task-free 工作在同一 PR 描述追加匿名来源摘要。可读原件沿用 `commit/path/blob/locator` 或真实公开锚点，先实际核对目标，再记录关系。原报告不存在公开锚点时保留未知；协调者摘要不冒充原报告，也不证明当时输入、机会或报告已固定。

以下只读命令仅是占位用法，日后对自然候选替换实际 commit 与仓库相对路径后使用；当前没有可执行的真实候选值。先核对提交，再定位该提交中的 blob，读取原内容并核对稳定 locator 的目标；本次读取或 hash 不证明观察入口前已固定。

```console
git show --no-patch --format=fuller <CANDIDATE_COMMIT>
git diff --name-only <BASELINE_COMMIT> <CANDIDATE_COMMIT> --
git ls-tree <CANDIDATE_COMMIT> -- <REPO_RELATIVE_PATH>
git show <CANDIDATE_COMMIT>:<REPO_RELATIVE_PATH>
```

候选与先前契约分别使用各自的固定提交；先前契约须核适用关系与入口前存在依据，不用候选中新改文字冒充旧契约。`ls-tree` 核对普通文件的 mode、blob 与路径，符号链接或子模块不按普通原件处理；提交显示的时间不独自证明输入固定或实际时序。

不另存审核输入、capture、原聊天、身份、会话日志或 oracle，不新增结果库、采集器或 Schema。公开保存仍按[既有边界](effect-observations.md#保存与隐私边界)执行；本页模板只供原 PR／CLI 流程中的人工语义说明，不是新增必填接口，也不能把模板字段送入现有 v2 块或 CLI Schema。

## 核对入口事实，再声明机会与窗口

未来被测审核开始前，核对固定候选、先前契约、允许材料、实际提示暴露、职责来源、平台、原预算及入口／关闭依据。正常契约预期可以提供；答案、被测报告、根因、修复或后继结果的可见性分别核对。正式 context 中的验证摘要原样保留，不能删字段后称未提示审核。

被测审核与独立裁定分别使用新上下文和最小允许材料列表，避免继承含根因、报告、答案、修复或后继结果的完整聊天历史。这是减少提示的操作办法，不是未提示的充分证明；实际输入及暴露时序无法复核时仍为未知。

按[采用范围第 4 节](../superpowers/specs/review-detection-admission.md#4-相关组选择与不足处理)在结局揭示前形成机会列表、实例粒度、唯一定位和相关组依据。每组只取本窗口第一个预声明候选中，按契约引用／对象引用／缺陷类别排序的第一项。跨 TASK／PR 的同任务、候选／修复链、共同输入、共同缺陷来源和共享故障也须关联；排序键无法消歧就保持未知。选中项后来为负或未知，不换正例；每组一项本身不证明组间独立或条件可比。

以下是可复制的准备声明。所有尖括号均为未填写占位，`unknown` 是当前缺口；删除占位或填写引用不产生就绪结论。真实事实核对及实现、数据／方法／质量条件成立后，才在原流程明确 UTC 的 `T0` 与 `T1=T0+30 days`，入口为 `[T0,T1)`。采用日、准备提交日或模板粘贴日都不自动成为 `T0`。

```markdown
研究准备声明：template_only；不是观察入口或真实结果
适用包：review-detection-admission-v0.1
自然工作与载体：<原 TASK／PR 引用；尚无实际候选>
协议与实际候选：<协议版本引用>；<候选 commit/tree 与原件定位>
先前契约与适用关系：<固定版本、要求定位及适用依据>
受检对象与实例粒度：<对象定位、直接矛盾类别及唯一实例规则>
机会形成及排除规则：<审核前固定的规则与完整列表原件引用>
相关组及预选项：<关联原件与理由>；<第一候选、排序及第一项依据>
审核条件与允许输入：<首次阶段、平台及原输入引用>
实际提示暴露与时序：unknown；<可复核依据，未核定不声明未提示>
协调／审核／非作者裁定／匹配职责：<既有职责来源；当前未核定>
原预算：<原授权、适用规则及已有上限引用>；实际投入 unknown；剩余 unknown
入口、输入与机会固定依据：unknown；<原件及可复核时序>
完整报告范围与预算关闭规则：<原安排引用；当前未核定>
观察窗口：T0 unknown；T1 unknown；尚未启动
后续报告／裁定／匹配／关闭原件：unknown；尚无真实结局
未满足事实及下一项机械核对：<缺口、原来源与责任>
```

复用[已有职责与预算](../superpowers/specs/2026-10-09-s1-contract-compatibility-and-review-budget.md#3-有界审核预算与职责合同候选)和自然工作自身的真实授权。数值上限、实际投入和剩余分别引用；未知不补零或无限。独立裁定未被原安排覆盖时，不据本模板增加一轮盲审、付费调用或补样本审核，先保留该缺口。已授权范围内的机械缺项由 Agent 补齐，不重复请求已采用的用途、精度或范围决定；真实来源、范围或风险变化才按现有规则集中交所有者。

## 固定报告后独立裁定，再匹配与关闭

被测报告及其实际候选、完整报告范围和预算端点先固定。由既有安排覆盖、非候选作者且非被测报告作者的裁定者，在未读取被测报告的条件下，按固定候选、契约和机会规则裁定；其职责、实际可见材料与时序须有可复核依据。不同 Agent 或一句“未读”声明不代替这些事实。修复后的受影响残余复核不能冒充首次独立裁定。固定裁定依据和争议后，才对照被测报告匹配；无需建立私密存储或提前公开答案。

正真值须有可检验预期、候选专属冲突及归因、适用关系和可处置影响；负与未知分别保留。匹配须同一实际候选、契约违约对象／机制和足够具体的错误行为，并引用理由与原件。重复 Finding 不增加机会；范围外新发现保留为后续反馈，不能倒填本轮列表。争议只在原预算内作受影响残余复核，保留双方依据，未闭合为未知。

仅在 `T1` 前实际关闭、独立正真值及预算内正确报告均有依据时，才支持预算内检出；未检出还须完整报告范围、明确入口、预算及关闭端点。取消、timeout、partial、工具／权限失败或未关闭保留原值，不能由“未见 Finding”补零；首次审核、受提示复核和修复后审核分别保留，不用后来通过覆盖原结果。

## 关闭后回读原值，条件满足才推进评分

回读复用[固定 Git 工具](review-feedback.md)或[公开 PR 工具](pr-feedback.md)，按原接口组织内存输入并经标准输入读取，不落盘新增副本。原报告、裁定和匹配依据继续引用原位置，公开 PR 只追加脱敏关系摘要。`matched_reported` 核对声明关联，不认证语义匹配、真值或实际修复；hash、APPROVE、resolved、CI 通过和填写完整均不证明真实观察就绪。

| 后续阶段 | 需要核对的真实事实 | 不足时的处理 |
|---|---|---|
| 观察入口 | 实现及数据／方法／质量条件、实际候选与来源、固定输入和机会、职责／预算、明确 UTC 窗口均成立。 | 保留准备声明与缺口，不设置 `T0` 或先行观察。 |
| 结局关闭 | 独立裁定及其信息条件、同候选语义匹配、完整报告与预算端点可复核，且在 `T1` 前关闭。 | 原值和冲突继续保留；不补检出、未检出或正真值。 |
| 真实分析与评分接入 | 机会选择、正真值、相关性、条件可比性、提示、缺失及方法适用性均能支持本窗口声明，并有相应真实输入实现与质量验证。 | 有影响主声明的未知即停止主比例／区间，只回读原值与缺口；不把真实计数标成 synthetic。 |

窗口结束后只作一次计划分析；不因精度不足延长窗口、重试、换机会或凑满 104。95% 覆盖／20 个百分点总宽和条件规划 104 沿用协议，不是样本配额或检出率阈值。真实条件成立仍须另推进对应真实评分实现，当前工具不会自动切换；模型评分更新、3-A 真实评分／shadow 与 Phase 3 不由本页准备完成。

最小反例：选中机会裁负后换成已检出正例，破坏预选规则；仅有可变 PR 摘要及 hash，不能证明审核前固定；裁定者已读 Finding 后与报告一致，不能补独立真值；窗口内入口但 `T1` 时未关闭，不能算未检出。上述情况均保留原件及未知，继续不依赖它们的已授权准备。
