## 语义变更

受控 runner 先将 POSIX 系统默认搜索路径中的绝对目录解析到物理目录，再按原来的次序去重。额外 Git 目录仍按原位置追加。这样 Ubuntu 子进程找到的 Git 和初始化器要求的目录身份一致。Windows 保留原有搜索顺序和相对条目。既有审批来源、任务版本绑定、按内容复用校验器及有效 PR 贡献范围的行为沿用已审核实现。

## 风险

如果将任意宿主工具目录排在系统目录之前，会改变其他程序的解析优先级。实现只处理 POSIX 默认目录，并保留专用初始化器对目录、链接及可执行文件的检查。路由仍须拒绝创建任务前已存在的治理改动，并保全失败与收尾记录。原始 CI 失败和前任审核各自保留版本绑定。
