## 禁止动作

不弱化 strict init 的路径/祖先检查，不将任意宿主目录或环境变量放入受控进程，不修改旧账本历史、本仓权限、分支保护和覆盖阈值。禁止直接推 main、强推、改写已推送历史、部署、删除数据、导出凭据、真实评分、外仓接入、付费调用。对外仅由主代理按常设授权交付一个核实的本仓 codex 分支。

## 错误行为

真实不安全或不可访问的 Git 路径继续按初始化边界拒绝。缺少可信候选或出现范围、身份、证据、基线漂移时，保留原生拒绝和失败证据；未通过的 required check 不触发合并。测试不能观察到实际 POSIX 行为时，明确缺口，不以 Windows 结果替代。
