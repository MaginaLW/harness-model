# Task Specification

## 目标

完善 AGENTS.md 中的开发、计划和并行协作指引，采用渐进式披露并保留现有治理约束。

## 范围

只修改 AGENTS.md，补充简洁工程原则、大型任务计划的串并联关系、适度委派及包括主 Agent 在内的十个 Agent 上限，遵守平台实际限制；按需引用既有文档，不复制平台适配入口。

## 非目标

不修改常设授权、Policy、维护模式、质量门槛和既有操作流程，不引入新的调度系统或任务模板。

## 验收条件

- 开发原则明确遵循 boring-engineering 并说明适用的简单实现与复用原则。
- 大型任务实施前制定计划，标明依赖串行链、独立并行批次和建议并行数；独立工作适时委派，限定写入归属，主 Agent 整合验证，Agent 总数不超过 10 且受宿主限制。
- 常用规则在入口简明表达，详细流程按需读取；现有治理规则与授权不变。
- 入口链接测试、独立设计与实现审核、CLI 所要求的完整验证和 Gate 通过。

## 禁止动作

不执行 push、merge、deploy、delete、secret_export 或 paid_external_call；不修改授权文件或降低治理要求。

## 错误行为

任务分类、审核或验证未通过时不得绕过门禁；存在超出常设授权的决定时按当前规则升级。

## 回滚

使用 Git 撤销本任务对 AGENTS.md 的修改，保留追加式任务、审核和证据记录。
