不改写、删除或转移 TASK-0114、TASK-0115、TASK-0118 及其他既有任务的规格、记录、证据、日志或明确禁令，不将来源未知的旧任务禁令解释为默认项，不复用旧任务的版本绑定审核、批准或验证证据。不修改 Policy、Schema、CLI、Hook 程序、CI、覆盖率阈值或分支保护，不移除或绕过实际集成的 Hook 或服务端拒绝，不传输未经授权的私有材料。配套文档由独立 PR 处理，不混入本任务的源码变更。

## 验收条件

- `AGENTS.md` 与所述已审候选的文件内容一致，覆盖目标授权内的任务拆分、技术选择、修复和独立复审，明确 spec、code 和本地 action 的批准条件与时序。
- 真实 ASK、已有任务禁令、用户决定、目标仓权限、高风险动作边界以及完整测试、85% 总覆盖率、90% diff coverage、whitespace、Ruff、format、mypy 和 required CI 均保持有效。
- 本任务冻结规格经独立设计审核；当前 subject 经独立实现审核、完整适用 V1、code 批准及 Gate 通过。规格批准的来源仅可记为所有者已直接明确授权该具体规则修改，不得声称较旧的常设代签条件自动满足。
- 对本任务 push/merge 分别记录精确 action 的目标、subject/ref、条件与有效期并人工核对已给出的所有者授权。只有适用任务约束、Policy、Hook 和目标仓规则满足且 required checks 全通过时才进行相关动作；合并使用 merge commit。
- 本地 Gate 或未主动调用 wrapper 不构成外部动作授权；旧任务、来源未知或显式禁止的动作不因本任务授权而获准。

当授权、目标、绑定、风险事实、审核、验证、禁令来源或目标仓权限缺失、失效或有冲突时停止相关动作；不得忽略真实 Hook 或服务器拒绝，不伪造通过、不改写旧记录。其余独立工作继续。
