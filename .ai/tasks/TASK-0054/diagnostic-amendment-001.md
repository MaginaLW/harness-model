# E4.1 诊断边界修订记录

独立只读审查发现：将未知字段名设为合成字符串
`credential=TOP_SECRET_VALUE` 时，现有 `additionalProperties` 诊断会把该字段名
写进 JSON Pointer，并原样返回给调用方。冻结规格要求失败诊断不回显敏感输入，
但原批准范围仅允许 `src/aiflow/contracts.py` 增加契约登记。

本次修订只允许对 `external-review` 的未知字段诊断返回已知父对象指针和稳定的
`unexpected property` 约束说明，不输出未知字段名或值。该规则覆盖根和嵌套对象；
现有契约沿用原有诊断行为。其他字段、状态、批准和 Gate 语义均不变。

安全测试应同时覆盖根与嵌套未知字段名的脱敏，以及既有契约的诊断兼容。该文件
记录需要重新分类、冻结、独立设计审查和当前规格批准的原因；它不是该批准本身。
